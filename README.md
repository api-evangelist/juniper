Juniper Networks (an HPE company since 2025) builds AI-native networking, routing, switching and security for service providers, enterprises and public-sector organizations. Its programmable surface spans the Mist cloud API (1,059 REST operations), Apstra data-center automation, Junos device automation over NETCONF/YANG, Junos Telemetry Interface gRPC streaming, and three first-party MCP servers.

**Areas:** Artificial Intelligence · Automation · Cloud · Enterprise · Networking · SDN · Security · Fortune 1000

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Juniper Networks: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
